# Sprint_7
Проектная работа 7-го спринта
Sprint_7: Тестирование API Яндекс Самоката
Описание проекта
Проект представляет собой набор автоматизированных тестов для API учебного сервиса Яндекс Самокат. В рамках проекта тестируются основные функциональные возможности сервиса: создание курьеров, авторизация, создание заказов и получение списка заказов.

Запуск тестов
# Установка зависимостей
pip install -r requirements.txt

# Запуск всех тестов
pytest

# Генерация Allure отчета
allure serve allure-results
Отчеты
После запуска тестов генерируется отчет Allure, который содержит подробную информацию о выполненных тестах, включая:

Статус прохождения
Время выполнения
Детальные логи
Скриншоты (при наличии)
Правила именования
Тесты: test_<feature>_<action>
Фикстуры: <feature>_<object>_<action>
Классы: Test<Feature>
Методы: test_<action>
